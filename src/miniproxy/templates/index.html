      Noise filter
      
    

    

      

        Browser traffic drowns out the target. Enabled rules are dropped at
        capture time, so they never enter the DB. Static assets (images,
        fonts, css, js, media) are always eligible — the bundled list covers
        common telemetry and ad hosts and ships disabled.
      

      

        
        
        
      

      

      

      

        
        
        
      

      

    

  







  

    

      Match & replace
      
    

    

      

        Rules are applied to requests as they pass through the proxy,
        before they reach the server — so the target sees the modified values.
        For headers, Exact matches the header name and sets its
        value; Contains and Regex match inside the value.
